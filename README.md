Pretoria Home Electronics – Website Project
This project is about creating a website for Pretoria Home Electronics (Pty) Ltd, an electronics business based in Pretoria, South Africa. The website gives customers information about the business, its products and services, and how to contact the company.

The aim of the website is to:
* Introduce the business to customers.
* Show the products and services offered.
* Make it easier for customers to send enquiries.
* Provide contact details and business information.
* Make the website easy to use on computers and mobile phones.

The website has five main pages:
* Home: Introduces the business and its products.
* About Us: Provides information about the business and its values.
* Products and Services: Shows the different electronics products.
* Enquiry: Allows customers to send product enquiries.
* Contact: Provides contact details, opening hours and the business location.

I used the following tools to create the website:
* HTML to create the website pages.
* CSS to add colours, fonts and layouts.
* JavaScript to add interactive features.
* Visual Studio Code to write and edit the code.
* GitHub to store my project files.
* GitHub Pages to publish my website.

The website includes:
* Navigation links between all five pages.
* A background image in the header with a dark overlay.
* A navy blue and orange colour theme.
* Product images and product cards.
* A product search feature.
* A mobile navigation menu.
* An enquiry form with validation.
* Clickable email links.
* A Google Maps location.
* An automatic copyright year.
